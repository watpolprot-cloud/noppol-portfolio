# นพพล ภาณุสุวัฒน์ · E-Portfolio

เว็บแฟ้มสะสมผลงานอิเล็กทรอนิกส์ของครูนพพล ภาณุสุวัฒน์ ครูชำนาญการพิเศษ
กลุ่มสาระการเรียนรู้วิทยาศาสตร์และเทคโนโลยี โรงเรียนพรตพิทยพยัต

## โครงสร้างไฟล์
- `index.html` หน้าเว็บหลัก (ไฟล์เดียว CSS/JS อยู่ในไฟล์)
- `tasks.html` หน้างานและกำหนดส่ง ดึงข้อมูลจาก Google Sheet ผ่าน Apps Script (แสดงเฉพาะงานที่ติ๊ก "แสดงบนเว็บ")
- `apps-script/Code.gs` โค้ด Apps Script ต้นฉบับที่วางไว้ใน Google Sheet ระบบติดตามงาน (ส่งข้อมูลให้ tasks.html และส่งอีเมลแจ้งเตือน)
- `assets/img/w/` ภาพประกอบผลงานและภาพบุคคล
- `assets/img/g/` ภาพกิจกรรมขนาดใหญ่ (เปิดในหน้าต่างขยาย)
- `assets/img/t/` ภาพกิจกรรมขนาดย่อสำหรับตาราง
- `docs/2569-2/` เอกสารประกอบการประเมิน ภาคเรียนที่ 2/2569 (PDF)
- `docs/2569-1/` เอกสารประกอบการประเมิน ภาคเรียนที่ 1/2569 (PDF)
- `assets/prev/` ภาพตัวอย่างเอกสาร (t.jpg = ภาพปก, p*.jpg = หน้าตัวอย่าง)
